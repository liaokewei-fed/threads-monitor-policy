1. 應用程式與營運者

「Threads Post Monitor」是單一營運者使用的私人監測工具，設計用途為取得指定的公開 Threads 帳號自行發布的原創公開貼文，並透過 LINE Messaging API 將通知傳送至營運者本人的 LINE 帳號。本工具沒有公開註冊功能，也不提供其他使用者使用。

  • 資料控管者／營運者：Threads Post Monitor（個人開發者）
  • 聯絡電子郵件：h630603@yahoo.com.tw

2. 目前狀態與資料流

目前原型狀態：官方 Threads 資料來源尚未啟用；程式在缺少授權時停止，在已有 Token 時也仍回報「尚未啟用」。目前沒有持續監測、沒有正式貼文擷取，也沒有持久化的貼文或去重資料庫。LINE 測試模組僅曾用環境變數中的憑證，將一則固定測試訊息送往營運者本人的 LINE User ID。
